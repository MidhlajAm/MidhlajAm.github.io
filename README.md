# Retro Portfolio

A black-and-white retro-themed developer portfolio for Midhlaj AM, featuring section navigation, pixel-art cards, and smooth animated interactions.

## Technologies Used

*   **Framework:** React
*   **Build Tool:** Vite
*   **Styling:** Tailwind CSS
*   **Hosting:** GitHub Pages

## Getting Started

To run this project locally:

1.  **Clone the repository**
2.  **Install dependencies:**
    ```bash
    npm install
    ```
3.  **Run the development server:**
    ```bash
    npm run dev
    ```

## Project Structure

*   `src/content/blogs/`: Markdown files for blog posts.
*   `src/data/`: JSON files containing data for projects, skills, achievements, and experience.
*   `src/components/`: Reusable React UI components.
